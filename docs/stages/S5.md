# S5 · 前端主题与 IA 全面替换 —— 交付与验收

阶段目标（[04-ROADMAP](../04-ROADMAP.md)）：让 harness 控制台成为**唯一的一等界面**，
上游 `web/` 退到回退位置。

---

## 一、交付结果

### 1. 入口与 IA 替换

| 路径 | 行为 | 说明 |
|---|---|---|
| `GET /` | **302 → `/app/`** | 入口换掉；书签、文档、README 均以控制台为准 |
| `GET /console`、`GET /console/` | 302 → `/app/` | 旧零构建控制台已下线，旧书签自动跳转 |
| `GET /app/*` | 内嵌静态资源（无条件 embed，`server/console-app/`） | 裸机 `go build` 即自带 UI |
| `GET /legacy/` | 302 → `/app/` | 上游 Next.js 前端已随源码移除 |
| `GET /api/*` | 不变 | JWT + CORS，上游路由一条未改 |

**为什么没有 `/legacy/` 回退通道**：上游 Next.js 前端已从仓库与构建链路中删除
（提交 `60dfcf2` 下线两套上游前端、`fdaa7e4` 删除 docs/demo 与 screenshots），
控制台是唯一 UI。旧路径保留 302 是为了让旧书签不 404，**不引入任何新能力**。

### 2. IA：五个一等公民视图

| 视图 | 职责 | 解决的缺口 |
|---|---|---|
| **Run** | 实时事件流按 revision 分组成轮次；就地 steer / 停止 / 编辑意图；顶部重规划/暂停/恢复 | ①③ 干涉成本 |
| **Plan** | frontier 按 worker 领取顺序列出；行内改摘要、改优先级、↑↓ 调序 → 保存顺序 | ① 意图不可改、不可排序 |
| **Replay** | 按 revision 区间重建运行、显示指纹与拦截数、可复制 Markdown | P2 可回放 |
| **Eval** | 同一份 CLI 判定结果的图形化：硬/软检查、PASS/FAIL、差异定位 | P4 一致性可测 |
| **平台** | 能力注册表（5 类供给面）+ 证据完整性（哪些结论有证据） | P1 能力即插件；证据可见 |

（`平台` 是 S5 新增视图，把 S4 的两个只读端点接进界面。）

### 3. 主题

自研暗色"instrument"风格，与上游 shadcn 仪表盘刻意不同：

- **等宽为主**：事件流、指纹、ID、revision 全部等宽，便于逐字比对；
- **轮次而非卡片墙**：左侧 2px 色条区分 planner（蓝）/ 人工（绿）/ work（灰）；
- **低 chrome**：无图表、无装饰；一屏内同时看到"发生了什么"和"我能做什么"；
- **同一套 token**：`--bg/--fg/--acc/--warn/--bad` 贯穿五个视图，新增视图无需新样式语言；
- 响应式：<1080px 时干预坞移到流下方，<1100px 时平台视图单列。

### 4. 内嵌链路复测

| 构建 | 结果 |
|---|---|
| `go build ./cmd/artex`（默认，无 tag） | ✅ 控制台可用（`/app/` 200，React 产物由 `go:embed` 无条件嵌入） |
| 运行时实测 | `GET /` → 302 `/app/`；`/app/` 200 `text/html`；`/app/assets/*.js` 200 `text/javascript`；`/app/../server.go` 404；`/api/health` 200 |

> 控制台**不需要** build tag，也不需要上游 Next 前端：`web/` 用 `vite build` 输出到
> `server/console-app/` 并提交进仓库，`go build` 直接内嵌。

## 三、S5 明确未做

| 未做 | 原因 |

| 删除 `web/` 目录与 `/legacy` 路由 | 需先确认控制台覆盖全部日常操作；删除不可逆 |

| 前端引入框架与构建链 | 与决策 4（裸机优先）冲突；零构建让每一步都能直接验证 |
