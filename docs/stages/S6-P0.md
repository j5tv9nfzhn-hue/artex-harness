## 不变量与取舍

1. **硬拒绝不可从 UI 删除**：DB 规则可删可禁，意图级 Critical 不行。这是 docs/02 §3.5 的结论：只留一小撮确定性拦截，但必须是机械的。
2. **无范围不拒绝**：legacy 任务未锚定范围时不中断，只记录。想收紧时，先给任务登记范围，再跑网络目标。
3. **沙箱不是容器**：`LocalSandbox` 只做路径、环境、主机策略，不启动容器。不要把它当成已隔离的执行环境来宣传，部署仍需专用主机或容器。
4. **不改提示词与既有管线**：只在 `guard` 前加两道关，不改 planner/worker 行为，不改模型可见文本（除被拦截时返回的平台管控前缀，沿用原有 `systemBlockMessage`）。
